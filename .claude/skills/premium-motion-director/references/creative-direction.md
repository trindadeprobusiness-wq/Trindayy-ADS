# Direção criativa e storytelling visual

## 1. Perguntas de partida (responder por escrito no brief)

1. O que o espectador precisa **entender**? (uma frase)
2. O que precisa **sentir**? (uma emoção dominante por ato)
3. Qual é a informação mais importante e onde a atenção deve estar em cada segundo?
4. Como o movimento melhora a compreensão (e não só decora)?
5. Como o som reforça (ou o silêncio enfatiza)?
6. Qual ação queremos? (um CTA)
7. Que estética combina com o posicionamento da marca? (premium ≠ cheio de efeitos)

## 2. Do roteiro ao conceito

Nunca coloque a frase do roteiro na tela e chame de motion. Para cada frase:

| Campo | Pergunta |
|---|---|
| Mensagem | O que ela afirma? |
| Emoção | Tensão, alívio, curiosidade, orgulho, urgência? |
| Conceito dominante | A palavra que carrega o sentido (ex.: "perde **tempo**") |
| Representação visual | Metáfora, objeto, interface, dado, tipografia pura? |
| Intensidade | 0 (quase estático) – 3 (expressivo) |
| Precisa de texto? | Sim / só a palavra-chave / não (a imagem diz) |
| Transição semântica | O elemento desta cena pode virar o da próxima? |
| Papel na narrativa | Gancho, problema, virada, prova, benefício, CTA |

Saída: uma **ideia-mestra** que atravessa a peça (ex.: "luz → ruído → ordem → clareza → produto"). Uma linha de pensamento contínua vale mais que cinco cenas bonitas desconexas.

### Exemplo trabalhado
Roteiro: "Enquanto você perde tempo com processos manuais, outras empresas estão automatizando tudo."
- Conceitos: perda de tempo, repetição, concorrência, transformação, automação.
- Opções (escolha conforme duração/público/marca, **não** use sempre a mesma):
  1. Repetição literal: barra de progresso que enche e reseta (usado no exemplo `dynamic-ad`).
  2. Contraste espacial: tela dividida — uma faixa lenta e solitária vs. fluxo rápido e organizado.
  3. Contraste temporal: o mesmo gesto feito 10× à mão vs. uma vez por um sistema.
  4. Caos → fluxo: elementos soltos que se conectam em um grafo.
  5. Tipográfico puro: "tempo" encolhendo enquanto "tudo" cresce.

## 3. Estrutura narrativa por duração

| Duração | Estrutura recomendada |
|---|---|
| 6–8 s (bumper) | 1 ideia + assinatura. Sem problema/solução. |
| 15 s | Gancho (0–2 s) → tensão/problema → virada → CTA (≥ 1,5 s de hold) |
| 30 s | Gancho → problema → virada → 2–3 provas/benefícios → CTA |
| 60 s+ | Atos com respiro; alternar cenas densas e simples; revelação no meio |

Hook: os primeiros 1–2 s precisam de movimento **ou** de uma frase que crie pergunta. Contenção também é gancho (um único ponto de luz no escuro).

## 4. Discernimento: quando NÃO animar

- A mensagem é um número ou promessa forte → deixe a tipografia parada e o som trabalhar.
- Logo/assinatura de marca premium → um movimento, não três.
- Depois de uma sequência rápida → um hold estático cria contraste e memória.
- Interface complexa → a câmera se move, a UI se comporta como o produto real (sem "dançar").

## 5. Hierarquia narrativa e atenção

- Um foco por momento. Se há dois elementos se movendo, um deles está errado (ou é movimento secundário mais lento e menor).
- Guie o olho com: contraste > tamanho > movimento > cor. O movimento chega antes, o contraste segura.
- Direção de leitura: entradas da esquerda/baixo; saídas para cima/direita indicam "avanço".

## 6. Continuidade
Prefira transições que **conectam ideias** (o anel vira portal, o card vira nó). Ver `cinematic-transitions.md`.

## 7. Honestidade comercial
- Produto real: só funcionalidades e números fornecidos/verificados. Sem dados → use rótulos neutros ou visual abstrato.
- Produto fictício/demonstração: sinalize na peça ("Demonstração · dados fictícios").
- Nunca prometa resultado ("+300% de vendas") sem fonte fornecida pelo cliente.
