# Exemplos (testes A, B, C)

O código de cada exemplo vive em `engine/src/examples/<nome>/` (componente + `timeline.json`) e é copiado para `<studio>/src/examples/` pelo `init-studio.sh`.
Os vídeos renderizados de referência estão no repositório de origem, em `motion-studio/renders/` (github.com/trindadeprobusiness-wq/O-Trindade). Cada pasta aqui guarda o brief, o storyboard resumido e a revisão crítica com a rubrica.

| Teste | Estilo | Formato | Duração | Nota (rubrica) |
|---|---|---|---|---|
| A Premium product | A | 1920×1080 | 15 s | 88/100 |
| B Dynamic ad | B+F | 1080×1920 | 18 s | 86/100 |
| C SaaS showcase | C | 1920×1080 | 18 s | 88/100 |

Nenhum atingiu a meta de 90 — os motivos estão em cada relatório (principalmente: sem narração real e trilha sonora sintética).
