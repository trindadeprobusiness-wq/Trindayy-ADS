# Checklist de produção

- [ ] Brief preenchido; premissas registradas
- [ ] Ideia-mestra + análise semântica
- [ ] Estilo escolhido e justificado; Theme criado/derivado
- [ ] Storyboard com intenção por cena
- [ ] timeline.json válido (`validate-assets.py` = pass)
- [ ] Narração: word-map gerado (ou limitação "só frase" registrada)
- [ ] `npx tsc --noEmit` sem erros
- [ ] Stills com `--safe` revisados (texto, área segura, sobreposição)
- [ ] Render MP4 + masterização −14 LUFS
- [ ] `validate-render.py` sem blockers
- [ ] Rubrica preenchida com evidências (meta ≥ 90)
- [ ] Correções aplicadas e re-validadas
- [ ] Entrega: MP4, fontes, timeline, brief, storyboard, relatório, limitações
